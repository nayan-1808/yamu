Messaging insights by audience

We can split the campaigns by how much someone already knows about Fathom when they search. Some have never heard of it and type generic terms like "AI notetaker". Some are shopping around, searching competitors like Otter or Fireflies. And some already know Fathom and search for it by name. Looking at what works in each group tells us which messages actually land, and that is useful beyond Google Ads.
